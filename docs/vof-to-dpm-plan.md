# VOF-to-DPM 近场雾化方案

> 目标：解析一次雾化（液膜/液柱破碎），得到物理上可信的下游粒径分布，
> 作为管式炉（解耦下游）的入口条件。

## 1. 模型在做什么

两段式：

1. **VOF 阶段**：用界面重构解析液膜、液丝、液块。液体的形状靠网格"看得见"。
2. **转换阶段**：当一个液块被网格解析得足够好（接近球形、直径在阈值内），
   Fluent 把它**替换成一个 DPM parcel**，之后按拉格朗日追踪（二次破碎、蒸发、碰撞）。

所以它不是"另一个 DPM 模型"，而是 **VOF 与 DPM 的接力**：大尺度靠 VOF，小尺度靠 DPM。

## 2. 三个硬门槛

### 门槛一：必须开 AMR（自适应网格）

液膜厚度在几十微米量级。如果不加密，VOF 根本"看不见"液膜，会算出假的破碎。

- 加密依据：VOF 梯度（界面）+ 速度梯度
- 加密级别：2–3 级
- 必须设**最小单元尺寸**（否则单元数失控）

### 门槛二：时间步被表面张力锁死

表面张力主导的毛细波要求：

```text
Δt < sqrt( ρ · Δx³ / (2π·σ) )
```

代入水（ρ=1000，σ=0.072）与 Δx = 20 μm：

```text
Δt < sqrt( 1000 × (2e-5)³ / (2π × 0.072) ) ≈ 4×10^-6 s
```

所以 **Δt 取 1e-6 s 量级**。物理时间要算到 20–50 ms（液膜破碎 + 喷雾稳定），
就是 **2–5 万步**。

### 门槛三：算力

| 维度 | 单元数（含 AMR） | 单机 32 核估计 |
|------|------------------|----------------|
| 2D 轴对称 | 200–500 万 | 数天到两周 |
| 3D 扇区（30°） | 2000–5000 万 | 数月，需上集群 |

**单元数怎么估**：开了 AMR 之后，单元数跟**界面面积**成正比，不是跟体积成正比。

```text
3D:  N ≈ (界面面积 / Δ²) × 层数
2D:  N ≈ (界面长度 / Δ)  × 层数      层数取 3–5
```

例：锥面 8×10⁻⁴ m²、Δ = 10 μm、4 层 → 3D 约 3200 万。
如果全域按 10 μm 均匀加密（不开 AMR），才会到 2–5 亿——那是 DNS 级做法，不是这里的选择。

**结论：必须用 2D 轴对称。** 3D 只在你已经有超算且能排队几周时才考虑。

## 3. 分阶段路线（每阶段都有产出，不要跳）

| 阶段 | 内容 | 产出 | 风险 |
|------|------|------|------|
| **S0** | 单相稳态，气路流场（中心气 + 旋流） | 收敛的速度场 | 低 |
| **S1** | 开 VOF（不加 DPM），液膜能否稳定喷出 | 液膜形态图 | 中：表面张力/接触角设置错会立刻散 |
| **S2** | 加 AMR，看液膜是否自然破碎出液丝 | 破碎图像 | 高：网格不够就是假破碎 |
| **S3** | 开 VOF-to-DPM 转换，取粒径分布 | 分布直方图 + SMD | 中：转换判据要调 |

S0 用稳态能省很多时间；S1 开始必须 transient。

## 4. 关键设置清单

### 多相模型
| 项 | 设置 |
|---|---|
| Model | Multiphase → **VOF**，2 相（air 主相，water-liquid 次相） |
| Scheme | **Explicit**，界面重构 **Geo-Reconstruct**（或 Compressive） |
| 表面张力 | **Continuum Surface Force**，勾 Wall Adhesion（接触角） |
| 体积分数离散 | 显式，Courant 数 ≤ 2 |

### 求解器
- Transient，**PISO**（VOF 首选）或 Coupled
- 压力：PRESTO! 或 Body Force Weighted（有重力/大密度差时）
- 动量：二阶迎风
- 时间推进：固定 Δt = 1e-6 s 起步，跑稳后再放大

### DPM 与转换
- Models → **Discrete Phase** 打开
- Multiphase 面板里勾 **VOF-to-DPM**
- 转换判据（关键参数）：
  - **最大等效直径**：超过这个尺寸的液块不转换（还太大，继续用 VOF 算）
  - **最小直径**：太小的不转换（网格解析不了，转了也是假的）
  - **球形度阈值**：越接近 1 越严格
- 转换后的 parc 统计权重决定质量守恒，务必检查总体液相质量

### 网格
- 基础网格：液膜区先给 50 μm 左右
- AMR：VOF 梯度 > 0.01 就加密，2–3 级
- 最小尺寸：**10–20 μm**（对应液膜厚度除以 5）

## 5. 最大的坑：假破碎

网格不够细时，VOF 会因为数值扩散"假装"把液膜撕碎，产生一堆假液滴。
这些假液滴被转换成 DPM 后，粒径分布完全不可信，而且看起来"很合理"，很难发现。

**判断方法**：
1. 做一次网格敏感性——单元加密一倍，SMD 变化应 < 10%
2. 检查液相体积随时间是否守恒（转换前后）
3. 看液膜破碎位置是否随网格变化而移动（移动了就是数值破碎）

## 6. 和管式炉解耦的接口

VOF-to-DPM 给出的分布，本质是"喷嘴下游某个截面的液滴统计"。交接给管式炉时要注意：

- 取**近场**截面（雾化刚完成、蒸发还没显著影响分布）
- 按**体积分数**而非数量分数给分布（DPM 注入用的是质量/体积流量）
- 同时给：SMD、分布直方图、喷雾锥角、该截面的速度剖面
