# 02 · 后台阶流动（Backward-facing step）

**目的**：练湍流模型选型与"再附着长度"这个经典验证量。
再附着点是分离泡的终点，用壁面摩擦系数 Cf = 0 的位置提取，是湍流建模里最常被讨论的判据之一。

## 设置

| 项目 | 方案 |
|------|------|
| 几何 | 按 Armaly (1983) 构型，扩张比 1:1.94，阶梯高 H |
| 工况 | 低 Re 与高 Re 各一组 |
| 湍流模型 | Realizable k-ε vs SST k-ω（对比组） |
| 网格 | 三套无关性；壁面 y+ 按所选模型处理 |
| 目标量 | 再附着长度 x/H（Cf = 0 位置） |

## 对标

- Armaly, B. F. et al., *J. Fluid Mech.* **127**:473–496 (1983).
- Driver, D. M. & Seegmiller, H. L., *AIAA J.* **23**:163–171 (1985)（高 Re，x/H ≈ 6.3）
- 通过线：再附着长度误差 ≤ 10%
