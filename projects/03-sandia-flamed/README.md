# 03 · Sandia Flame D 湍流燃烧

**目的**：在无实验条件的课题背景下，用国际公认的 TNF 基准火焰完成一次
"端到端燃烧仿真验证"——这是本作品集的核心项目。

## 火焰背景

Sandia/TUD piloted CH4/air jet flame D，是湍流非预混燃烧模型验证的标杆算例：
射流外围有一圈值班火焰（pilot）稳定主火焰，火焰在 x/d ≈ 45–50 处达到温度峰值，
之后逐渐熄灭。它同时包含**局部熄火与再点火**，是检验 EDC / Flamelet 类模型的好靶子。

| 参数 | 值 |
|------|-----|
| 喷嘴直径 | d = 7.2 mm |
| pilot 外径 | 18.2 mm |
| 燃料 | 25% CH4 + 75% air（体积） |
| U_fuel | 49.6 m/s |
| Re | 22 400 |
| pilot | φ = 0.77，功率约为主火焰的 6% |

## 复盘要点

- pilot 的边界条件怎么给（平衡组分 + 温度）直接决定火焰稳定性，最容易出错的地方。
- RANS 在 x/d > 60 的熄火段通常高估温度——这是模型局限，不是你的错，写清楚就是加分项。
