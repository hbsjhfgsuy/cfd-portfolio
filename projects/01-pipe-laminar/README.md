# 01 · 圆管层流（Poiseuille 流）

**目的**：验证求解器与后处理流程本身没问题。解析解存在，误差应当是"接近零"，
如果这一步就差 20%，后面所有结果都不可信。

## 设置

| 项目 | 方案 |
|------|------|
| 几何 | 圆管 L/D = 50，2D 轴对称（或 3D 楔形 5°） |
| 工况 | Re = 1000（层流，Re < 2300） |
| 边界 | 入口速度 / 出口压力 / 壁面无滑移 |
| 网格 | 三套，约 2 倍逐级加密（轴向 × 径向同步） |
| 目标量 | 出口充分发展速度剖面、沿程压降 |

## 对标

- 速度剖面：u/U_mean = 2[1 − (r/R)²]
- 压降：Darcy 摩擦因子 f = 64/Re
- 通过线：相对误差 < 1%
