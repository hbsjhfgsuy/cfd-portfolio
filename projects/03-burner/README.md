# 03 · 燃气灶大气式燃烧器（2027.3 – 2027.5）

**目的**：把前两个项目练的方法论迁移到家电场景。这是与家电行业真实工程场景最贴近的项目——
不需要做到产品级，做到"设置合理 + 结论清晰 + 有敏感性分析"就够。

## 建模思路（抓物理、砍细节）

| 部件 | 简化方式 |
|------|----------|
| 燃烧器头 | 环形/单排火孔，孔径 1–2 mm |
| 锅底 | 等温壁面或定热流壁面 |
| 燃烧 | 大气式部分预混，一次空气系数 0.4–0.8 扫描 |
| 模型 | 部分预混 Flamelet（FGM）或 EDC |
| 物理 | 重力开启；密度按不可压理想气体处理浮力；**DO 辐射必开**（灶具辐射占比大） |
| 网格 | 火孔附近加密，全局 20–100 万单元 |

## 输出

- 火焰高度/形状（与燃气灶火焰照片定性对比）
- 火孔出口温度、锅底热流分布
- CO / NOx / 热效率随一次空气系数的趋势（4–5 组扫描）
- 热效率估算 = 锅底吸热 / 热负荷

## 对标与自检

- 文献设置参照：Boggavarapu et al., *Fuel* **116** (2014)
- 无直接实验时的物理自检：热负荷↑ → 火焰高度↑；一次空气系数↑ → CO↓、火焰变短
- 标准参照：GB 30720（一级能效热效率 ≥ 63%）、GB 16410-2020（干烟气 CO ≤ 0.05%）

## 复盘要点

- 火孔附近网格要细到能解析射流出口，但全局网格会爆——用局部加密而非整体加密
