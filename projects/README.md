# projects/

每个项目一个目录，结构统一：

```text
0X-项目名/
├─ README.md        项目说明 + 对标结果（报告主体，先写这里）
├─ setup.md         求解器设置表（边界条件、模型、离散格式、收敛判据）
├─ figures/         对标图、网格图、残差图
├─ data/            自算结果（与参考数据的对比 CSV）
└─ case/            求解器输入（.cas/.jou/配置；大文件不入库）
```

## 判定标准（每个项目开工前写死）

| 项目 | 关键量 | 通过线 |
|------|--------|--------|
| 01 圆管层流 | 出口速度剖面、压降 | 误差 < 1% |
| 02 后台阶 | 再附着长度 x/H | 误差 ≤ 10% |
| 03 Flame D | 轴向温度峰值位置与量值 | 误差 < 15% |
