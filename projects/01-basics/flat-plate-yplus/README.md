# 01c · 平板湍流边界层（y+ 专题）

**目的**：把 y+ 从"书上的公式"变成"我调过、我量过"的经验。这是壁面处理的第一道门槛，
也是最容易被追问到露馅的地方。

## 设置

| 项目 | 方案 |
|------|------|
| 几何 | 平板，入口段 + 充分发展段，长宽比足够 |
| 工况 | Re_x 到 1e6 量级，不可压 |
| 网格 | 两套：y+ ≈ 30（壁面函数） vs y+ ≈ 1（SST 低雷诺数，膨胀层 10–15 层） |
| 目标量 | 第一层网格高度、y+ 云图、壁面摩擦系数 Cf、速度剖面对数律 |

## 对标

- 速度剖面：u+ = (1/κ)ln(y+) + B（κ≈0.41，B≈5.0）
- 壁面摩擦系数：Cf = 0.0592 Re_x^(-1/5)（1/5 次方律）或 Schlichting 经验式
- 通过线：对数律区斜率与截距合理；两套网格的 Cf 差异 < 5%

## 结果

⬜ 待补充（y+ 云图 + 两套网格的对数律剖面对比 + Cf 沿程曲线）

## 复盘

⬜ 待补充：第一层网格高度怎么反算的（用 Re 和 Cf 估算 uτ），实际 y+ 与设计值差多少
