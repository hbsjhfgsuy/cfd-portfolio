## 1. 几何

| 项 | 值 |
|---|---|
| 维度 | **2D 轴对称（Axisymmetric）** |
| 平面 | x-y 平面，**对称轴就是 x 轴（y = 0）** |
| 域 | x: 0 → 1.2 m；y: 0 → 0.005 m |
| 边界命名 | inlet（x=0）、outlet（x=1.2）、wall（y=0.005）、axis（y=0） |

⚠️ 三个必错点：

1. **别选 Planar。** 平面通道的摩擦因子是 f = 96/Re，比圆管的 64/Re 大 50%，压降差一半——这是最常见的"怎么差这么多"的原因。
2. **对称轴必须是 axis 类型**，不能设成 wall，否则等于算了一个半管。
3. y=0 那条边不参与流动，只提供对称条件。

## 2. 网格（三套，约 2 倍加密）

| 网格 | 轴向 × 径向 | 单元数 | 用途 |
|---|---|---|---|
| coarse | 240 × 30 | 7 200 | 快速验证设置对不对 |
| medium | 480 × 60 | 28 800 | 日常计算 |
| fine | 960 × 120 | 115 200 | 最终结果 |

- 单元类型：全四边形（Quad），结构化 Mapped Face
- 轴向：均匀分布即可（层流没有强轴向梯度）
- 径向：向壁面适度加密（bias factor 3–5），因为壁面附近速度梯度最大
- 质量目标：最小正交质量 > 0.9（四边形结构网格基本都能到 0.99）

层流对网格不敏感——**这本身就是一个要写进报告的结论**：三套网格压降差异应该 < 1%，
如果差很多，说明设置有问题（而不是"网格不够密"）。

## 3. 求解设置

| 项 | 设置 |
|---|---|
| Solver | Pressure-Based，Steady |
| 2D Space | **Axisymmetric** |
| Viscous | **Laminar**（Re=995，不开湍流模型） |
| 材料 | water-liquid（ρ = 998.2 kg/m³，μ = 0.001003 Pa·s） |
| 入口 | velocity-inlet，0.1 m/s，垂直于边界 |
| 出口 | pressure-outlet，表压 0 Pa |
| 壁面 | no-slip，静止 |
| Operating pressure | 101325 Pa（默认） |
| 压力-速度耦合 | SIMPLE |
| 离散格式 | 压力 Second Order；动量 Second Order Upwind |
| 收敛判据 | 残差 1e-6 **且** 进出口质量流率不平衡 < 0.1% |

层流的残差通常 100–200 步内掉到 1e-6，如果卡在 1e-3 不动，几乎一定是边界条件设错了。

## 5. 压降怎么比才不会"冤枉"自己

这里有个坑：**全程压降包含入口发展段的额外损失**。

- 理论值 38.52 Pa 是"充分发展段"的压降，对应 1.2 m 全长
- 但入口段（前 0.6 m）流场还在发展，额外多耗散约 1.24 × (ρU²/2) ≈ 6.2 Pa
- 如果直接拿入口到出口的总压降去比 38.52 Pa，会得到 ≈ 44.7 Pa，**偏高 16%**，看起来像做错了

正确的两种做法（选一个，写进报告）：

**做法 A（推荐）**：取充分发展段的压降，即 x=0.7 → 1.2 m（0.5 m 长）这一段，
理论值 = 0.06431 × (0.5/0.01) × (998.2×0.01/2) = **16.05 Pa**，两者应吻合到 1% 以内。

**做法 B**：入口直接给抛物线剖面（用 Profile 文件或 UDF），全场充分发展，总压降直接等于 38.52 Pa。

顺便：**能主动指出入口效应并扣除它，比误差 0.5% 更能说明你懂这题。**
