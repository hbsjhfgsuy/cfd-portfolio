# 01a · 圆管层流（Poiseuille 流）

**目的**：验证整个流程（几何 → 网格 → 求解 → 后处理 → 对标）本身没问题。
解析解存在，误差应当"接近零"——这一步就差 20%，后面所有结果都不可信。

## 基本设置

| 项目 | 值 |
|------|-----|
| 几何 | L = 1.2 m，D = 10 mm，2D 轴对称（L/D = 120） |
| 工况 | Re = 995（水，U_mean = 0.1 m/s），层流 |
| 湍流模型 | 无（Laminar） |
| 网格 | 三套：7 200 / 28 800 / 115 200 单元 |
| 目标量 | 充分发展段速度剖面、压降 |

完整设置表见 [setup.md](setup.md)（边界条件、离散格式、收敛判据、后处理采集项）。

## 对标依据

| 量 | 解析解 | 理论值 |
|----|--------|--------|
| 速度剖面 | u(r) = 2·U_mean·[1 − (r/R)²] | u_max = 0.2 m/s |
| 压降 | f = 64/Re，Δp = f·(L/D)·ρU²/2 | 38.52 Pa（全程） |
| 充分发展段压降 | 同上，取 L = 0.5 m | 16.05 Pa（x = 0.7–1.2 m） |
| 通过线 | 最大相对偏差 | **< 1%** |

## 怎么做

```bash
python scripts/analytical.py     # 1. 先生成解析解 CSV + 打印理论值
# 2. 在 Fluent 里按 setup.md 跑三套网格，导出 data/profile_*.csv
python scripts/compare.py        # 3. 出图 + 误差表 + 网格无关性表
```
