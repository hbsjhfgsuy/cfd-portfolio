# 01d · 翅片散热器共轭传热

**目的**：练共轭传热（固体 + 流体耦合）与"换热量收敛"的判断。这是家电 CFD 的日常场景——
空调整机、换热器、电机散热都是这一类问题。

## 设置

| 项目 | 方案 |
|------|------|
| 几何 | 官方 Tutorial 的翅片散热器，或简化平行翅片阵列 |
| 物理 | 强制对流 + 固体导热（共轭），开重力可选 |
| 模型 | SST 或 Realizable k-ε；壁面 y+ 按模型处理 |
| 目标量 | 换热量 Q、压降 ΔP、翅片效率 |
| 收敛判据 | 残差 3 个量级 + 换热量与出口温度同时稳定 + 能量不平衡 < 1% |

## 对标

- 与官方教程给出的参考值对比
- 物理自检：加大风速 → Q 上升但边际递减；翅片间距过小 → 压降陡增
- 通过线：与教程值偏差 < 10%，能量守恒检查通过
